Connect to GitLab

Create a personal access token to access your GitLab documents. It is saved in this browser.

  1. Open Personal access tokens, then choose Generate token → Legacy token.
  2. Enter a Token name and set an Expiration date.
  3. Select read_repository, read_api, write_repository and api.
  4. Click Generate token, then copy the token and paste it below.
